It documents the API exported by the native server.c implementation and provides substantial GSVE examples for HTML websites, reusable templates, product catalogs, shopping carts, sales records, inventory workflows, admin dashboards, JSON endpoints, middleware, file delivery and HTTPS.

Architecture and setup

The server is an optional native module, not a language keyword. The program imports it with import server;. The C module exposes route registration, a socket listener, response helpers, template/file functions and libcurl-based outbound HTTP functions.

Request lifecycle

Client TCP listener request parser route match matching middleware route handler response serialization client

The current listener accepts a connection and forks a child process to handle it. That matters for application design: ordinary in-memory mutations made while handling a request are not a durable shared database. Use a database or another persistent store for carts, stock, orders and user records.

Build and install

  1. Open the greenServeFE build repository and run its manual workflow for building the construct and server native modules.
  2. Install the resulting server.so (and construct.so if you use it) in a directory searched by the native module loader.
  3. Configure GREENSERVE_MODULE_PATH and, where required by the shared libraries, LD_LIBRARY_PATH.
  4. Run the GSVE program with the greenServeFE executable.
export GREENSERVE_MODULE_PATH=/usr/local/lib/modules
export LD_LIBRARY_PATH=/usr/local/lib/modules:$LD_LIBRARY_PATH
greenServeFE app.gsve

The exact package contents and linked system libraries depend on the module build workflow and release. Confirm that the installed shared object is compatible with the VM native-module ABI.

First server: a complete small site

Create app.gsve. The server root is the current directory; this minimal example disables automatic static serving and explicitly registers its routes.

import server;

func home(req, res) {
    res.status(200);
    res.set("X-Powered-By", "greenServeFE");
    res.html("<!doctype html><html lang='en'><head><meta charset='utf-8'><title>My site</title></head><body><h1>Hello from GSVE</h1><p>A native HTTP route.</p></body></html>");
}

func health(req, res) {
    res.json({ok: true, service: "storefront"});
}

server.get("/", home);
server.get("/health", health);
server.serve(".", 8080, {host: "0.0.0.0", static: false});

Open http://127.0.0.1:8080/ on the machine running the server. If you bind to 0.0.0.0, the listener accepts connections on available IPv4 interfaces; use firewall rules to control who can reach it.

Routes, methods, parameters and matching

Register handlers before calling serve. A route handler receives exactly two arguments: func handler(req, res). Named path segments use a colon; a wildcard segment is supported by the route matcher. Exact routes are preferred over less-specific matches. Middleware registered with use is prefix-matched.

Named route parameters and query strings

import server;

func product_detail(req, res) {
    define product_id = req.params.id;
    define page_number = req.query.page;
    res.json({
        id: product_id,
        page: page_number,
        route: req.path
    });
}

func search(req, res) {
    res.json({
        term: req.query.q,
        sort: req.query.sort,
        raw_query: req.queryString
    });
}

server.get("/products/:id", product_detail);
server.get("/search", search);
server.serve(".", 8080, {static: false});

For /products/sku-42?page=2, the path parameter is available as req.params.id; query parameters are available as properties of req.query. Query decoding handles percent-encoded values and plus signs.

Read a form submission

import server;

func contact_submit(req, res) {
    define name = req.form.name;
    define email = req.form.email;
    define message = req.form.message;

    if (name == null || email == null || message == null) {
        res.status(400);
        res.json({ok: false, error: "Missing required form fields"});
        return;
    }

    res.json({ok: true, received: {name: name, email: email}});
}

server.post("/contact", contact_submit);
server.serve(".", 8080, {static: false});

Read a JSON request body

The native request parser exposes the body as text and marks JSON content types with req.isJson. This server module does not itself provide a JSON parser for turning arbitrary request-body text into a nested GSVE object. For production JSON APIs, use a JSON parsing module available in your build, or accept explicitly defined form fields. Do not assume req.body is already an object.

Response examples

func created(req, res) {
    res.status(201);
    res.set("Location", "/api/items/42");
    res.json({ok: true, id: 42});
}

func not_found(req, res) {
    res.status(404);
    res.type("text/plain; charset=utf-8");
    res.send("Resource not found");
}

func redirect_to_shop(req, res) {
    res.redirect("/shop");
}

func export_file(req, res) {
    res.download("exports/catalog.csv", "catalog.csv");
}

Response helpers end the response when they send a body. Set the status and headers before sending. res.send is polymorphic: strings are emitted as text; other supported VM values are serialized as JSON.

Middleware and request guards

Middleware is registered with server.use(prefix, handler). Its signature is func middleware(req, res, next). Call next() to continue. Sending a response or returning without calling next() stops the chain. Middleware executes in registration order for matching prefixes.

import server;

func request_headers(req, res, next) {
    res.set("X-Content-Type-Options", "nosniff");
    res.set("X-Frame-Options", "DENY");
    res.set("Referrer-Policy", "strict-origin-when-cross-origin");
    next();
}

func admin_gate(req, res, next) {
    define token = req.headers["X-Admin-Token"];
    if (token == "replace-this-demo-token") {
        next();
    } else {
        res.status(401);
        res.json({ok: false, error: "Authentication required"});
    }
}

server.use("/", request_headers);
server.use("/admin", admin_gate);

func admin_home(req, res) {
    res.html("<h1>Admin area</h1>");
}
server.get("/admin", admin_home);
server.serve(".", 8080, {static: false});
Authentication example warning: the hard-coded token above is only a teaching illustration. Do not deploy a shared token embedded in source. Use a persistent user/session system, strong secrets from environment configuration, secure cookies, and authorization checks on every protected operation. The server's cookie helper is not a complete session framework.

HTML templates with server.render

The server template engine replaces {{name}} placeholders using values from an object. Dotted paths such as {{customer.name}} are supported. A missing or null value produces an empty substitution. It does not implement loops, conditions, includes, layouts or automatic HTML escaping.

Template file: views/product.html

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <title>{{product.name}} | Northstar Shop</title>
  <link rel="stylesheet" href="/assets/site.css">
</head>
<body>
  <header><a href="/">Northstar Shop</a></header>
  <main>
    <p>SKU: {{product.sku}}</p>
    <h1>{{product.name}}</h1>
    <p>{{product.description}}</p>
    <strong>{{product.price_label}}</strong>
    <form method="post" action="/cart/add">
      <input type="hidden" name="sku" value="{{product.sku}}">
      <label>Quantity <input type="number" name="quantity" value="1" min="1"></label>
      <button type="submit">Add to cart</button>
    </form>
  </main>
</body>
</html>

Route that renders the template

import server;

func product_page(req, res) {
    define product = {
        name: "Field Notebook",
        sku: "NOTE-01",
        description: "A durable everyday notebook.",
        price_label: "$12.00"
    };
    res.render("views/product.html", {product: product});
}

server.get("/products/notebook", product_page);
server.serve(".", 8080, {static: false});
Critical template safety: the current C template renderer inserts values directly into the output. It does not HTML-escape them. Never interpolate user-submitted names, descriptions, search strings, comments or database content into HTML without escaping for the correct output context. Prefer construct.escape(value) when using the construct module, or a reviewed context-aware escaping routine. Attribute values and JavaScript contexts need their own escaping rules. Do not treat a template placeholder as safe by default.

Inline templates with server.render

The module-level server.render(template, data) function renders a template string in memory; res.render(file, data) reads a template file beneath the server root and sends the rendered HTML response.

import server;

func welcome(req, res) {
    define template = "<main><h1>Hello, {{profile.name}}</h1><p>Plan: {{profile.plan}}</p></main>";
    define page = server.render(template, {
        profile: {name: "Ada", plan: "Starter"}
    });
    res.html(page);
}

server.get("/welcome", welcome);
server.serve(".", 8080, {static: false});

Generate semantic HTML with construct

The optional construct module complements the server. Use it to create complete documents, semantic elements, metadata, links, styles and scripts from GSVE. Its element/text helpers escape text and validate supported attributes; the page body, CSS and JavaScript slots are trusted raw insertion points.

import construct;
import server;

define navigation =
    "<nav>" +
    construct.link("Home", "/") +
    construct.link("Products", "/products") +
    construct.link("About", "/about") +
    "</nav>";

define main_content =
    construct.element("h1", "A shop generated by GSVE") +
    construct.element("p", "HTML is composed in the server program.") +
    construct.element("a", "Browse the catalog", {href: "/products"});

define document = construct.page({
    lang: "en",
    title: "Northstar Shop",
    body: navigation + "<main>" + main_content + "</main>",
    css: "body{font:16px system-ui;margin:0;color:#172033}nav{padding:1rem;background:#10243a}nav a{color:white;margin-right:1rem}main{max-width:900px;margin:3rem auto;padding:1rem}",
    js: "console.log('Northstar Shop ready');"
});

func home(req, res) {
    res.html(document);
}

server.get("/", home);
server.serve(".", 8080, {static: false});

Complete example: product storefront

This example shows a multi-route shop with a home page, product listing, product details, a search route, an HTML checkout form, a cart submission endpoint and order confirmation. It is a runnable teaching skeleton with a small in-memory catalog. The catalog is read-only; the cart/order confirmation is illustrative and is not persistent. For real transactions, store cart and order records in gs_db or another durable database.

import construct;
import server;

define products = [
    {sku: "BAG-100", name: "Canvas Field Bag", category: "Bags", price: 38, stock: 12, description: "A practical everyday carry bag."},
    {sku: "NOTE-210", name: "Hardcover Notebook", category: "Stationery", price: 14, stock: 40, description: "A sturdy notebook for plans and ideas."},
    {sku: "LAMP-310", name: "Desk Lamp", category: "Home", price: 52, stock: 7, description: "Adjustable light for a focused workspace."},
    {sku: "MUG-410", name: "Ceramic Mug", category: "Home", price: 18, stock: 25, description: "A simple ceramic coffee mug."}
];

func money(value) {
    return "$" + str(value);
}

func layout(title, content) {
    define nav = "<header><a href='/'>Northstar Market</a><nav>" +
        construct.link("Shop", "/products") +
        construct.link("About", "/about") +
        construct.link("Cart", "/cart") +
        "</nav></header>";
    return construct.page({
        title: title + " | Northstar Market",
        lang: "en",
        body: nav + "<main class='container'>" + content + "</main>",
        css: "body{margin:0;font:16px system-ui;color:#182536;background:#f4f7fb}header{display:flex;justify-content:space-between;padding:1rem 5%;background:#14283e;color:white}header a{color:white;margin-right:1rem}main{max-width:1050px;margin:2rem auto;padding:1rem}.cards{display:grid;grid-template-columns:repeat(auto-fit,minmax(220px,1fr));gap:1rem}.card{background:white;border:1px solid #dce4ed;border-radius:12px;padding:1rem}.price{font-size:1.3rem;font-weight:bold;color:#087f5b}button{padding:.7rem 1rem;background:#087f5b;color:white;border:0;border-radius:7px}input{padding:.6rem;border:1px solid #ccd5df;border-radius:6px}",
        js: ""
    });
}

func find_product(sku) {
    for product in products {
        if (product.sku == sku) {
            return product;
        }
    }
    return null;
}

func home(req, res) {
    define body = "<section><h1>Useful things, thoughtfully selected.</h1>" +
        "<p>Browse the catalog and discover the current collection.</p>" +
        "<a href='/products'>Explore products </a></section>";
    res.html(layout("Welcome", body));
}

func product_list(req, res) {
    define cards = "";
    for product in products {
        define safe_name = construct.escape(product.name);
        define safe_sku = construct.escape(product.sku);
        define safe_category = construct.escape(product.category);
        cards = cards + "<article class='card'><p>" + safe_category + "</p>" +
            "<h2>" + safe_name + "</h2>" +
            "<p class='price'>" + money(product.price) + "</p>" +
            "<p>Available: " + str(product.stock) + "</p>" +
            "<a href='/products/" + safe_sku + "'>View details</a></article>";
    }
    res.html(layout("Products", "<h1>Product catalog</h1><div class='cards'>" + cards + "</div>"));
}

func product_detail(req, res) {
    define product = find_product(req.params.sku);
    if (product == null) {
        res.status(404);
        res.html(layout("Not found", "<h1>Product not found</h1><a href='/products'>Back to shop</a>"));
        return;
    }
    define safe_name = construct.escape(product.name);
    define safe_description = construct.escape(product.description);
    define safe_sku = construct.escape(product.sku);
    define body = "<article><p>" + construct.escape(product.category) + "</p>" +
        "<h1>" + safe_name + "</h1><p>" + safe_description + "</p>" +
        "<p class='price'>" + money(product.price) + "</p>" +
        "<p>In stock: " + str(product.stock) + "</p>" +
        "<form method='post' action='/cart/add'>" +
        "<input type='hidden' name='sku' value='" + safe_sku + "'>" +
        "<label>Quantity <input type='number' name='quantity' value='1' min='1' max='10'></label> " +
        "<button type='submit'>Add to cart</button></form></article>";
    res.html(layout(product.name, body));
}

func search_products(req, res) {
    define term = req.query.q;
    if (term == null) {
        term = "";
    }
    define matches = "";
    for product in products {
        if (contains(str(product.name), str(term))) {
            matches = matches + "<li>" + construct.link(product.name, "/products/" + product.sku) + "</li>";
        }
    }
    res.html(layout("Search", "<h1>Search results</h1><ul>" + matches + "</ul>"));
}

func cart_add(req, res) {
    define sku = req.form.sku;
    define quantity = num(req.form.quantity);
    define product = find_product(sku);
    if (product == null || quantity < 1 || quantity > 10 || quantity > product.stock) {
        res.status(400);
        res.html(layout("Cart", "<h1>Unable to add item</h1><p>Check the SKU, quantity and stock.</p>"));
        return;
    }
    res.cookie("last_sku", product.sku, 86400, false);
    res.html(layout("Cart", "<h1>Added to cart</h1><p>" +
        construct.escape(product.name) + " × " + str(quantity) + "</p>" +
        "<p>This demo confirms the form flow but does not persist cart contents.</p>" +
        "<a href='/products'>Continue shopping</a>"));
}

func checkout_form(req, res) {
    define body = "<h1>Checkout</h1><form method='post' action='/checkout'>" +
        "<label>Full name <input name='customer' required></label><br>" +
        "<label>Email <input type='email' name='email' required></label><br>" +
        "<label>Delivery address <textarea name='address' required></textarea></label><br>" +
        "<button type='submit'>Place demo order</button></form>";
    res.html(layout("Checkout", body));
}

func checkout_submit(req, res) {
    if (req.form.customer == null || req.form.email == null || req.form.address == null) {
        res.status(400);
        res.html(layout("Checkout error", "<h1>Please complete all fields.</h1>"));
        return;
    }
    res.status(201);
    res.html(layout("Order received", "<h1>Thank you, " +
        construct.escape(req.form.customer) + "</h1><p>Your demo order was received.</p>"));
}

func about(req, res) {
    res.html(layout("About", "<h1>About Northstar Market</h1><p>A sample storefront built with GSVE routes and native HTML helpers.</p>"));
}

server.get("/", home);
server.get("/products", product_list);
server.get("/products/:sku", product_detail);
server.get("/search", search_products);
server.post("/cart/add", cart_add);
server.get("/checkout", checkout_form);
server.post("/checkout", checkout_submit);
server.get("/about", about);

server.serve(".", 8080, {host: "0.0.0.0", static: false, index: "index.html"});
Important example limitation: the storefront catalog is static demonstration data. The current server forks a child for each accepted connection, so changing a GSVE array during one request does not create a reliable cross-request cart or inventory store. Persist every order, cart and stock change in SQLite or another database. Also add CSRF protection, authentication, payment-provider verification, idempotency and transaction handling before accepting real orders or money.

Inventory management: products, stock and restocking

Inventory requires durable storage. The following illustrates the route design and validation boundary; connect the persistence calls to the installed gs_db module and use parameterized SQL. Do not replace database persistence with mutable global arrays in a fork-per-request server.

Inventory page and adjustment form

import construct;
import server;

func inventory_page(req, res) {
    define rows =
        "<tr><td>BAG-100</td><td>Canvas Field Bag</td><td>12</td><td>38.00</td></tr>" +
        "<tr><td>NOTE-210</td><td>Hardcover Notebook</td><td>40</td><td>14.00</td></tr>" +
        "<tr><td>LAMP-310</td><td>Desk Lamp</td><td>7</td><td>52.00</td></tr>";
    define body = "<h1>Inventory</h1><p>Review current stock levels and record a restock.</p>" +
        "<table><thead><tr><th>SKU</th><th>Product</th><th>On hand</th><th>Unit price</th></tr></thead><tbody>" +
        rows + "</tbody></table>" +
        "<h2>Record stock adjustment</h2><form method='post' action='/admin/inventory/adjust'>" +
        "<label>SKU <input name='sku' required></label>" +
        "<label>Quantity change <input name='delta' type='number' required></label>" +
        "<label>Reason <select name='reason'><option>restock</option><option>correction</option><option>damaged</option></select></label>" +
        "<button type='submit'>Save adjustment</button></form>";
    res.html(construct.page({title: "Inventory", body: body}));
}

func inventory_adjust(req, res) {
    define sku = req.form.sku;
    define delta = num(req.form.delta);
    if (sku == null || req.form.delta == null || delta == 0) {
        res.status(400);
        res.json({ok: false, error: "A SKU and non-zero quantity change are required"});
        return;
    }
    # Replace this point with a parameterized database transaction:
    # 1. Read the current quantity for this SKU.
    # 2. Reject unknown SKUs and any result below zero.
    # 3. Update products.stock and insert an inventory_movements row.
    # 4. Commit both writes together.
    res.status(202);
    res.json({ok: true, sku: sku, quantity_change: delta, reason: req.form.reason, persisted: false});
}

server.get("/admin/inventory", inventory_page);
server.post("/admin/inventory/adjust", inventory_adjust);
server.serve(".", 8080, {static: false});

Suggested relational schema

CREATE TABLE products (
    id INTEGER PRIMARY KEY,
    sku TEXT NOT NULL UNIQUE,
    name TEXT NOT NULL,
    description TEXT NOT NULL DEFAULT '',
    price_cents INTEGER NOT NULL CHECK (price_cents >= 0),
    stock INTEGER NOT NULL DEFAULT 0 CHECK (stock >= 0),
    active INTEGER NOT NULL DEFAULT 1
);

CREATE TABLE inventory_movements (
    id INTEGER PRIMARY KEY,
    product_id INTEGER NOT NULL,
    quantity_delta INTEGER NOT NULL,
    reason TEXT NOT NULL,
    created_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (product_id) REFERENCES products(id)
);

Use integer minor currency units (for example cents) instead of floating-point values for money. Keep an append-only movement record so stock changes can be audited. Apply stock changes atomically and prevent a sale from making stock negative.

Sales, orders and checkout

A sales system needs an order header, order lines, customer details, payment state and inventory movement records. The route handlers below show the HTTP contract and validation pattern; the persistence and payment provider integration must be implemented in the application layer.

File helpers are rooted beneath the server's configured document root and apply path-safety checks. Keep private configuration, database files, uploaded files and TLS private keys outside publicly served directories. Never build a filesystem path directly from untrusted request text.

The native listener supports TLS when built with its OpenSSL dependencies. Supply a certificate and matching private key. The listener uses a TCP socket, accepts connections, and handles each accepted connection in a forked child process.

Security, correctness and production readiness

  • Escape output: route parameters, form values, query values and database strings are untrusted. Escape HTML text and attributes before inserting them into markup. The low-level server template renderer is raw substitution; construct helpers are safer for text and link generation.
  • Validate input: check required fields, lengths, numeric ranges, allowed enum values and SKU formats. Reject malformed values before database work.
  • Use parameterized SQL: never concatenate user input into SQL. Use transactions for order creation and stock changes.
  • Protect state-changing routes: add authentication, role checks, CSRF defenses and audit records. Hiding an admin URL is not authorization.
  • Protect secrets: keep keys, tokens, database files and environment configuration out of public directories and version control.
  • Restrict file access: do not allow user-controlled paths to reach sendFile, download or filesystem helpers.
  • Use TLS: protect credentials and sessions in transit. Configure secure cookies only behind correctly configured HTTPS.
  • Control exposure: bind to loopback for local testing; use a firewall and a carefully configured reverse proxy for public deployments.
  • Monitor process behavior: each accepted connection is handled by a forked child. This is not an event-loop server, and request-local memory is not shared between child processes.
  • Load test before deployment: verify concurrency, process limits, file descriptor limits, memory use, error behavior and TLS configuration on the target host.
Capabilities not claimed by this source: the inspected server.c listener does not establish a complete production framework with rate limiting, graceful shutdown APIs, response compression, WebSocket upgrades, streaming response bodies, request-body streaming or persistent keep-alive sessions. Do not document or depend on those as implemented features unless the C source and tests are extended to provide them.
