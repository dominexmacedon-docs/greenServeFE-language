Native Module API

Form Validation and Conversion

Helpers for required fields, email-like input, conversions, string lengths and numeric ranges.

Purpose

Helpers for required fields, email-like input, conversions, string lengths and numeric ranges.

Exports registered by the module initializer

ExportRole
trimtrim exported function or value
requiredrequired exported function or value
is_emailis email exported function or value
to_numberto number exported function or value
to_boolto bool exported function or value
min_lengthmin length exported function or value
max_lengthmax length exported function or value
in_rangein range exported function or value

Usage example

import gs_form;
print(gs_form.trim("  Ada  "));
print(gs_form.required("name", "Ada"));
print(gs_form.is_email("ada@example.com"));
print(gs_form.to_number("42"));
to_number and to_bool return null for invalid input. Email validation is a practical syntax check, not mailbox verification.
