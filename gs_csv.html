Native Module API

CSV Parsing and Serialization

Convert CSV text into structured row data and serialize arrays of string fields to CSV text.

Purpose

Convert CSV text into structured row data and serialize arrays of string fields to CSV text.

Exported API

ExportRole
parseparse native function or exported value
stringifystringify native function or exported value

Usage example

import gs_csv;
define rows = gs_csv.parse("name,score\nAda,98\nGrace,95");
print(rows);
print(gs_csv.stringify([["name", "score"], ["Ada", "98"]]));
CSV is intended for text and arrays of string fields. Quote and delimiter handling should be checked against the current source implementation for edge cases.
