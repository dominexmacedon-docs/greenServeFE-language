Usage example

import gsnum;
define values = [4, 8, 15, 16, 23, 42];
print(gsnum.sum(values));
print(gsnum.mean(values));
print(gsnum.dot([1, 2], [3, 4]));
This module has a broad numerical API. Matrix dimensionality and input-shape constraints are implementation-specific; validate shapes and use tolerance-based tests for floating-point results.
