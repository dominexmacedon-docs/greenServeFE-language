gs_compute: Complete API and Usage

A native C numerical toolkit for financial calculations, descriptive statistics, vectors, matrix algebra, linear systems, numerical integration and differentiation, unit conversion, numeric comparisons, benchmarking, and reproducible random sampling. This reference follows the module's exported functions and validation logic.

At a glance

41 exported functions Native C CPU IEEE-754 double Module ABI v1

Import the module once with import gs_compute;, then call its functions through the module object. The module does not add language keywords or change the VM.

1. Build, install and import

gs_compute is implemented in C as a native shared-library module. Build it using the gs_compute build workflow in the greenServeFE build repository, then place gs_compute.so in a directory searched by the native module loader.

# Example installation location
/usr/local/lib/modules/gs_compute.so

# Make the module directory visible to the process
export GREENSERVE_MODULE_PATH=/usr/local/lib/modules
export LD_LIBRARY_PATH=/usr/local/lib/modules:$LD_LIBRARY_PATH

Run a GSVE file after the module is installed:

import gs_compute;

print(gs_compute.info());
print(gs_compute.percent(250, 12));
The source file existing in a checkout does not mean its shared object is already built or installed. The VM must be able to locate a compatible gs_compute.so at runtime.

2. GSVE language usage

Examples use the actual greenServeFE language forms: define for variable declarations, func for functions, semicolons for statements, arrays with square brackets, and object values with braces. Module functions are called with dot-member access.

import gs_compute;

define values = [12, 18, 24, 30];
define summary = gs_compute.stats(values);

print(summary.mean);
print(summary.median);
print(summary.stddev);

func price_after_discount(price, rate) {
    return gs_compute.discount(price, rate);
}

print(price_after_discount(120, 15));

All numeric arguments must be GSVE numbers. Numeric strings are not automatically parsed by this module. Convert text deliberately with the language's numeric conversion facilities before calling a numerical API.

3. Financial and percentage APIs

percent(value, percentage)

Returns value * percentage / 100. The percentage may be negative or greater than 100; both inputs must be finite numbers.

print(gs_compute.percent(250, 12)); # 30

percent_change(before, after)

Returns the signed percentage change: (after - before) / abs(before) * 100. Returns null when before is zero.

print(gs_compute.percent_change(80, 100));  # 25
print(gs_compute.percent_change(100, 80));  # -20

discount(price, percentage)

Returns the price after applying a discount. Requires price >= 0 and 0 <= percentage <= 100.

define sale_price = gs_compute.discount(250, 20);
print(sale_price); # 200

tax(price, percentage)

Returns price including the percentage tax: price * (1 + percentage / 100). Requires a non-negative price and percentage.

print(gs_compute.tax(200, 5)); # 210

tip(bill, percentage, people?)

Calculates a tip and split. people defaults to 1 and, when supplied, must be a positive integer. Returns an object with tip, total, and per_person.

define split = gs_compute.tip(120, 15, 4);
print(split.tip);         # 18
print(split.total);       # 138
print(split.per_person);  # 34.5

compound(principal, annual_rate_percent, years)

Calculates compound growth with annual compounding. The four-argument overload compound(principal, annual_rate_percent, periods_per_year, years) selects the compounding frequency. Principal must be non-negative; rate must be greater than -100%; periods must be a positive integer; years must be between 0 and 100000.

define annual = gs_compute.compound(1000, 5, 3);
define monthly = gs_compute.compound(1000, 5, 12, 3);
print(annual);
print(monthly);

loan_payment(principal, annual_rate_percent, months)

Returns the fixed monthly payment for a fully amortizing loan. Months must be a positive integer (maximum 120000); principal and annual rate must be non-negative. A zero interest rate returns principal / months.

define payment = gs_compute.loan_payment(12000, 6, 24);
print(payment);

4. Scalar and numeric helpers

clamp(value, lower, upper)

Constrains a number to the inclusive bounds. If lower is greater than upper, the implementation swaps the bounds.

print(gs_compute.clamp(125, 0, 100)); # 100

lerp(start, end, t)

Linear interpolation or extrapolation: start + (end - start) * t. Values of t outside 0–1 extrapolate.

print(gs_compute.lerp(10, 20, 0.25)); # 12.5

map_range(value, input_min, input_max, output_min, output_max)

Maps a value linearly from one range to another. The input range endpoints must differ; the value is not clamped to the input range.

print(gs_compute.map_range(5, 0, 10, 0, 100)); # 50

sum(numbers)

Returns the sum of a non-empty or empty numeric array (an empty array sums to zero). Every element must be a finite number; the array limit for this function is 1,000,000 values.

print(gs_compute.sum([10, 20, 30])); # 60

quadratic(a, b, c)

Solves a*x*x + b*x + c = 0 for real roots. Returns a two-element array in minus-root then plus-root order. Returns null if a is zero or the discriminant is negative.

define roots = gs_compute.quadratic(1, -5, 6);
print(roots[0]); # 2
print(roots[1]); # 3

5. Statistics APIs

stats(numbers)

Returns a descriptive-statistics object: count, sum, mean, min, max, median, range, variance, and stddev. Variance is population variance (divisor N), and standard deviation is its square root. Median sorts a copy of the input values.

define s = gs_compute.stats([2, 4, 4, 4, 5, 5, 7, 9]);
print(s.count);     # 8
print(s.mean);      # 5
print(s.median);    # 4.5
print(s.variance);  # 4
print(s.stddev);

mean(numbers)

Returns the arithmetic mean using an incremental mean update. Requires at least one finite numeric value.

print(gs_compute.mean([2, 4, 6, 8])); # 5

variance(numbers)

Returns population variance using Welford's online update. Requires at least one finite numeric value.

print(gs_compute.variance([2, 4, 6, 8]));

6. Vector APIs

Vectors are one-dimensional GSVE arrays of finite numbers. Operations that combine two vectors require equal lengths.

dot(vector_a, vector_b)

Returns the dot product, the sum of pairwise products. Both vectors must have the same non-zero length.

print(gs_compute.dot([1, 2, 3], [4, 5, 6])); # 32

vector_add(vector_a, vector_b)

Returns element-wise addition of two equally sized vectors.

print(gs_compute.vector_add([1, 2], [10, 20])); # [11, 22]

vector_sub(vector_a, vector_b)

Returns element-wise subtraction a - b.

print(gs_compute.vector_sub([10, 20], [1, 2])); # [9, 18]

vector_scale(vector, scalar)

Multiplies every vector element by a finite scalar.

print(gs_compute.vector_scale([1, 2, 3], 2)); # [2, 4, 6]

norm(vector)

Returns the Euclidean (L2) norm. Uses a scaled sum-of-squares algorithm to reduce overflow and underflow risk. The vector must be non-empty.

print(gs_compute.norm([3, 4])); # 5

7. Matrix APIs

Matrices are rectangular arrays of equally sized row arrays. Every cell must be a finite number. Matrix operations reject ragged rows and incompatible dimensions.

matrix_add(matrix_a, matrix_b) and matrix_sub(matrix_a, matrix_b)

Element-wise addition or subtraction. Both matrices must have identical row and column counts.

define a = [[1, 2], [3, 4]];
define b = [[5, 6], [7, 8]];
print(gs_compute.matrix_add(a, b));
print(gs_compute.matrix_sub(b, a));

transpose(matrix)

Returns a new matrix with rows and columns exchanged. Rectangular matrices are supported.

print(gs_compute.transpose([[1, 2, 3], [4, 5, 6]]));
// [[1, 4], [2, 5], [3, 6]]

matmul(matrix_a, matrix_b)

Performs matrix multiplication. If A has shape r × k, B must have shape k × c, and the result has shape r × c. The C implementation uses cache-friendly blocked multiplication.

define product = gs_compute.matmul(
    [[1, 2], [3, 4]],
    [[5, 6], [7, 8]]
);
print(product); # [[19, 22], [43, 50]]

matrix_vector(matrix, vector)

Multiplies an r × c matrix by a vector of length c; returns a vector of length r.

print(gs_compute.matrix_vector([[1, 2], [3, 4]], [5, 6]));
// [17, 39]

matrix_determinant(matrix)

Computes the determinant of a square matrix using Gaussian elimination with partial pivoting. A singular matrix returns numeric zero; malformed or non-square input returns null.

print(gs_compute.matrix_determinant([[1, 2], [3, 4]])); # -2

matrix_inverse(matrix)

Computes the inverse of a square non-singular matrix using Gauss–Jordan elimination with scaled partial pivoting. Singular or numerically rejected matrices return null.

define inverse = gs_compute.matrix_inverse([[4, 7], [2, 6]]);
print(inverse);

zeros(rows, columns)

Creates a matrix of the requested positive integer dimensions, filled with zeros.

print(gs_compute.zeros(2, 3)); # [[0, 0, 0], [0, 0, 0]]

identity(size)

Creates a square identity matrix of the requested positive integer size. The current implementation accepts sizes up to 3162.

print(gs_compute.identity(3));
// [[1, 0, 0], [0, 1, 0], [0, 0, 1]]

solve(matrix_a, vector_b)

Solves the square linear system A*x = b using Gaussian elimination with scaled partial pivoting. The vector length must equal the matrix dimension. Singular or numerically unstable systems return null.

define solution = gs_compute.solve(
    [[2, 1], [1, 3]],
    [8, 13]
);
print(solution); # [2.2, 3.6]

8. Numerical methods

integrate(x_values, y_values)

Approximates the definite integral for sampled data using the composite trapezoidal rule. The two arrays must have equal length of at least two. X values must be non-decreasing; repeated x values contribute zero width.

define area = gs_compute.integrate(
    [0, 1, 2, 3],
    [0, 1, 2, 3]
);
print(area); # 4.5

differentiate(x_values, y_values)

Returns a derivative estimate at every sample. It uses forward difference at the first point, backward difference at the last point, and a two-point central difference for interior points. X coordinates must be strictly increasing wherever a stencil is evaluated; duplicate or decreasing coordinates return null.

define slope = gs_compute.differentiate(
    [0, 1, 2, 3],
    [0, 1, 4, 9]
);
print(slope);

linspace(start, end, count)

Creates count evenly spaced numbers including both endpoints when count is greater than one. When count is one, the result contains only start. Count must be a positive integer.

print(gs_compute.linspace(0, 1, 5)); # [0, 0.25, 0.5, 0.75, 1]

9. Unit conversion

convert(value, from_unit, to_unit)

Converts a number between supported units in the same dimension. Unit strings are case-sensitive. Identical unit strings return the input value.

DimensionSupported units
Lengthm, km, cm, mm, mi, ft, in, yd
Masskg, g, mg, lb, oz
Times, ms, min, h, day
Decimal data sizeB, KB, MB, GB (base 1000)
Binary data sizeKiB, MiB, GiB (base 1024)
TemperatureC, F, K
print(gs_compute.convert(5, "km", "m"));   # 5000
print(gs_compute.convert(32, "F", "C"));   # 0
print(gs_compute.convert(1, "GiB", "MB")); # 1073.741824

Temperature conversions use Celsius as the intermediate scale. Kelvin values below absolute zero are rejected. Unsupported units and cross-dimension conversions return null.

10. Validation and benchmarking

is_close(a, b, absolute_tolerance?, relative_tolerance?)

Returns a boolean indicating whether abs(a-b) <= abs_tol + rel_tol * max(abs(a), abs(b)). Both tolerances default to 1e-9 and must be non-negative.

print(gs_compute.is_close(0.1 + 0.2, 0.3));
print(gs_compute.is_close(1000, 1000.1, 0.001, 0.0002));

is_null(value)

Returns true only when the first supplied argument is the VM's null value. If no argument is supplied, returns false.

define result = gs_compute.matrix_inverse([[1, 2], [2, 4]]);
print(gs_compute.is_null(result));

benchmark_stats(count)

Runs a fixed internal workload: generates values cycling from 0 through 999, computes Welford mean and variance, sorts the generated values, and measures CPU time. Returns an object containing count, elapsed_ms, mean, variance, min, max, median, and workload. Count must be an integer from 1 through 10,000,000.

define result = gs_compute.benchmark_stats(100000);
print(result.count);
print(result.elapsed_ms);
print(result.workload);

This benchmarks the module's fixed statistics workload, not arbitrary user functions or the entire VM. Timings vary by CPU, system load and compiler build.

11. Seeded random APIs

The random generator is deterministic and intended for simulation, sampling and reproducible experiments. It is not cryptographically secure. Do not use it for passwords, tokens, keys, authentication secrets or security-sensitive identifiers.

random_seed(seed)

Sets the module's deterministic pseudo-random generator state and returns true on success. The seed must be a finite number with absolute value no greater than 9007199254740991. A zero seed is mapped to the generator's non-zero default state.

print(gs_compute.random_seed(12345));

random(minimum?, maximum?)

Returns a pseudo-random floating-point value in the half-open interval from the lower bound up to (but not including) the upper bound. Defaults are 0 and 1. If bounds are reversed, they are swapped.

gs_compute.random_seed(7);
print(gs_compute.random());       # [0, 1)
print(gs_compute.random(10, 20));  # [10, 20)

random_array(count, minimum?, maximum?)

Returns an array of pseudo-random floating-point values. Count must be an integer from 0 through 10,000,000. Bounds default to 0 and 1 and are swapped when supplied in reverse order.

gs_compute.random_seed(42);
define samples = gs_compute.random_array(5, -1, 1);
print(samples);

12. Module metadata

info()

Returns metadata about the loaded module:

  • name: "gs_compute"
  • version: "2.1.0"
  • backend: "native C CPU"
  • numeric_type: "IEEE-754 double"
  • status: a capability summary string
define details = gs_compute.info();
print(details.name);
print(details.version);
print(details.backend);

13. Types, limits and null results

  • Numeric values: numerical parameters must be finite GSVE numbers. Numeric strings are not accepted as numbers.
  • Arrays: vector and data-array functions require arrays containing only finite numbers. Matrix functions require non-empty rectangular nested arrays of finite numbers.
  • Invalid input: most validation failures, unsupported units, incompatible dimensions, singular inverses/linear systems, non-finite calculations and allocation failures return the VM value null. matrix_determinant is a special case: a valid singular square matrix returns numeric zero.
  • Statistics: stats and sum cap the input at 1,000,000 values. Scientific array and matrix helpers use a 10,000,000-element guard, subject to shape-specific and memory checks.
  • Matrix creation: zeros requires positive integer dimensions and limits total cells to 10,000,000. identity currently accepts sizes up to 3162.
  • Precision: values use C double / IEEE-754 floating-point. Exact decimal equality is not guaranteed; use is_close for approximate comparisons.
  • Randomness: the PRNG state is shared by calls to this module instance. Reseeding resets the sequence. It is not a cryptographic random source.
When an API returns null, inspect argument types, array shape, dimensions, bounds and numeric finiteness. Use gs_compute.is_null(result) to test the returned value explicitly.

14. Complete GSVE example: sales and scientific calculations

import gs_compute;

# Sales calculations
define unit_price = 89.50;
define quantity = 12;
define subtotal = unit_price * quantity;
define discount_amount = gs_compute.percent(subtotal, 10);
define discounted = gs_compute.discount(subtotal, 10);
define total = gs_compute.tax(discounted, 5);

print("Subtotal:");
print(subtotal);
print("Discount amount:");
print(discount_amount);
print("Total after discount and tax:");
print(total);

# Statistics for daily sales
define daily_sales = [120, 135, 98, 160, 145, 172, 155];
define report = gs_compute.stats(daily_sales);
print("Average daily sales:");
print(report.mean);
print("Median daily sales:");
print(report.median);
print("Population standard deviation:");
print(report.stddev);

# Vector and matrix calculations
define demand = [10, 15, 20];
define unit_cost = [3, 4, 5];
print("Weighted total:");
print(gs_compute.dot(demand, unit_cost));

define matrix_a = [[2, 1], [1, 3]];
define matrix_b = [[8, 1], [13, 2]];
print(gs_compute.matmul(matrix_a, matrix_b));
print(gs_compute.solve(matrix_a, [8, 13]));
print(gs_compute.matrix_inverse(matrix_a));

# Sampled numerical data
define x = [0, 1, 2, 3, 4];
define y = [0, 1, 4, 9, 16];
print("Approximate area:");
print(gs_compute.integrate(x, y));
print("Approximate derivative:");
print(gs_compute.differentiate(x, y));

# Reproducible experiment
gs_compute.random_seed(2026);
define samples = gs_compute.random_array(8, 0, 100);
print(samples);
print(gs_compute.stats(samples));
