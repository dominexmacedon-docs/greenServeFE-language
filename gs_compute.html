Scientific, Financial and Matrix Computation

A native numerical toolkit covering financial calculations, statistics, vectors, matrices, numerical methods, conversions and reproducible random helpers.

Usage example

import gs_compute;
print(gs_compute.percent(250, 12));
print(gs_compute.compound(1000, 5, 3));
print(gs_compute.matrix_determinant([[1, 2], [3, 4]]));
print(gs_compute.linspace(0, 1, 5));
Exported function names are listed from the module initializer. Consult the source-level argument validation for exact accepted arity and object fields; use numeric tolerances for approximate algorithms.
