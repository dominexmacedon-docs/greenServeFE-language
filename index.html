Install on Linux

Install MacoraOne first. The installer places the executable at /usr/local/bin/one.

Install MacoraOne

Run this complete command in a Linux terminal. It downloads the v1.0.2 release, extracts the executable, and installs it as one.

set -eu

URL="https://github.com/MacoraOne/MacoraOne/releases/download/one-v1.0.2/macoraone-linux-x86_64.zip"
TMP_DIR="$(mktemp -d)"
trap 'rm -rf "$TMP_DIR"' EXIT

curl -fL "$URL" -o "$TMP_DIR/macoraone-linux-x86_64.zip"
unzip -q "$TMP_DIR/macoraone-linux-x86_64.zip" -d "$TMP_DIR/extracted"

# Locate the executable inside the archive.
BIN="$(find "$TMP_DIR/extracted" -type f \( -name 'macoraone' -o -name 'macoraone-linux-x86_64' -o -name 'one' \) -print -quit)"

if [ -z "$BIN" ]; then
    echo "Error: could not find the MacoraOne executable in the release archive." >&2
    echo "Archive contents:" >&2
    find "$TMP_DIR/extracted" -maxdepth 3 -type f -print >&2
    exit 1
fi

chmod +x "$BIN"
sudo install -m 0755 "$BIN" /usr/local/bin/one

echo "MacoraOne installed as the 'one' command at /usr/local/bin/one"
one --help
Requirements: curl, unzip, and permission to install the executable into /usr/local/bin. If your Linux distribution does not already include curl or unzip, install those system packages first.

Install greenServeFE

Use MacoraOne to install or remove the language package.

# Install the greenServeFE language package
one install greenServeFE

# Check the command
greenServeFE --help

# Remove the greenServeFE language package
one uninstall greenServeFE

Manage modules with MacoraOne

Install and uninstall packages individually. Use the exact package name and version published in the MacoraOne catalogue.

Install one module

Install a module by its package name, optionally with a published version.

one install server
one install server@1.0.0

Install another module

Run a separate command for each additional module.

one install gs_regex
one install gs_json

Uninstall a module

Remove an individual module by package name.

one uninstall server
one uninstall gs_regex

Install or uninstall all

Use the catalogue-wide commands when you intend to manage all available packages.

one install all
one uninstall all

MacoraOne is the unified project for package and tool management. For predictable results, install one package per command; repeat the command for each module you need. The availability of a package depends on the published catalogue.

Your first greenServeFE program

Create a file named hello.gsve, then run it with the greenServeFE command.

1. Create hello.gsve

print("Hello, greenServeFE!");
print("Welcome to programming.");

2. Run the program

greenServeFE hello.gsve

Example using a module

After installing the corresponding module, import it in your program and call its functions.

import gs_regex;

define email_shape = "^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\\.[A-Za-z]{2,}$";

print(gs_regex.match("ada@example.com", email_shape));
print(gs_regex.test("order-2048", "^order-[0-9]+$"));
print(gs_regex.replace_first("green green", "green", "blue"));

Save source files with the .gsve extension. The command-line form is greenServeFE filename.gsve. Consult the detailed guide and module-usage PDF for the language reference and supported module APIs.
