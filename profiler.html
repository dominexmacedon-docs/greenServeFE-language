Performance Tools

greenServeFE VM Profiler

Measure VM execution time, bytecode throughput, opcode counts, hot source lines, stack and frame peaks, and inclusive function timing.

Run profiling

greenServeFE --profile program.gsve

Profiling is opt-in and observes executed bytecode instructions in the VM dispatch loop. Ordinary runs do not print a profiling report.

Report fields

  • Elapsed VM execution wall-clock time.
  • Total bytecode instructions and approximate instruction throughput.
  • Executed opcode counts and CALL opcode count.
  • Peak operand-stack depth and peak VM frame depth.
  • Inclusive elapsed time and invocation counts for VM functions/code objects.
  • Up to 20 hottest source locations by instruction count.

Interpretation and limits

Elapsed time includes time spent in native functions called by the script. Opcode counts measure VM dispatches, not native C instructions. Hot source locations are ranked by dispatch count, not CPU time. Function timing is inclusive, so child calls are also counted in callers. The profiler does not track heap allocations, native instruction counts or sampling-based CPU profiles.
