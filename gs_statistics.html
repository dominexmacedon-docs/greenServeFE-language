Native Module API

Descriptive Statistics API

Compute sums, means, medians, variance, standard deviation and extrema.

Purpose

Compute sums, means, medians, variance, standard deviation and extrema.

Exports registered by the module initializer

ExportRole
sumsum exported function or value
meanmean exported function or value
medianmedian exported function or value
variancevariance exported function or value
stddevstddev exported function or value
minmin exported function or value
maxmax exported function or value

Usage example

import gs_statistics;
define values = [2, 4, 6, 8, 10];
print(gs_statistics.mean(values));
print(gs_statistics.median(values));
print(gs_statistics.variance(values));
print(gs_statistics.stddev(values));
Check the implementation's population/sample variance convention. Use tolerances when testing floating-point output.
