Native Module API

gs_validate — Input Validation

Practical validation helpers for email-like strings, integer syntax, numeric syntax and nonempty text.

Exported API

  • email(value) — checks whether a value resembles an email address.
  • integer(value) — checks whether the complete input is an integer representation.
  • numeric(value) — checks whether the complete input parses as a number.
  • nonempty(value) — checks whether the string representation is nonempty.

Example

import gs_validate;
print(gs_validate.email("ada@example.com"));
print(gs_validate.integer("2026"));
print(gs_validate.numeric("19.75"));
print(gs_validate.nonempty("GSVE"));

Email checking is a practical format check, not mailbox verification. Numeric validation requires the full string to parse as a number. Use this module as input validation, not as a substitute for server-side authorization or business rules.
