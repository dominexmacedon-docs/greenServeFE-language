gs_validate — Input Validation

Practical validation helpers for email-like strings, integer syntax, numeric syntax and nonempty text.

Exports

  • email(value)
  • integer(value)
  • numeric(value)
  • nonempty(value)

Example

import gs_validate;
print(gs_validate.email("ada@example.com"));
print(gs_validate.integer("2026"));
print(gs_validate.numeric("19.75"));
print(gs_validate.nonempty("GSVE"));

Email checking is a practical format check, not mailbox verification. Numeric validation requires the full string to parse as a number.
