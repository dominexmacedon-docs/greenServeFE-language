Import and loading

Native modules are compiled C shared objects loaded by the greenServeFE VM. Use import module_name; and install the matching module_name.so in a searched directory.

export GREENSERVE_MODULE_PATH=/usr/local/lib/modules
export LD_LIBRARY_PATH=/usr/local/lib/modules:$LD_LIBRARY_PATH
