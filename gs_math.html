Scalar Mathematics

Scalar mathematical helpers and constants for common arithmetic, rounding, logarithmic and exponential operations.

Purpose

Scalar mathematical helpers and constants for common arithmetic, rounding, logarithmic and exponential operations.

Usage example

import gs_math;
print(gs_math.sqrt(81));
print(gs_math.pow(2, 10));
print(gs_math.clamp(150, 0, 100));
print(gs_math.pi);
This module is distinct from gsnum and gs_compute; use its small scalar API for basic math.
